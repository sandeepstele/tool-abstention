# Competent 0.5B SFT screening initializer

## Why a replacement was required

The original 20-step 0.5B SFT adapter was designed only to prove that MLX LoRA
could train and reload. Full behavioral evaluation later showed 0% act accuracy,
so it could not detect DPO over-abstention. A promotion screen needs an initializer
that already calls tools meaningfully.

## Frozen training run

The replacement uses the same pinned Qwen2.5 0.5B revision and internal-only
360/120 SFT corpus. It trained for 180 batches (one data epoch), batch size 2,
accumulation 8, learning rate `2e-5`, 16 LoRA layers, rank 16, and maximum length
1024. The adapter SHA-256 is
`f788f9f7048282380ae2a2815018bb331a470ded0c6c51bcd8ef47a95a4677f4`.
Peak training memory was approximately 7.13 GB.

## Behavioral baseline

| Metric | Original validation | Protocol stress |
|---|---:|---:|
| Accuracy | 80.83% | 0.00% |
| Behavior accuracy | 83.33% | 25.00% |
| Act accuracy | 63.33% | 0.00% |
| Abstention accuracy | 98.33% | 0.00% |
| Protocol compliance | 100.00% | 87.50% |
| Hallucinated-call rate | 0.00% | 50.00% |

The model is weaker than the selected 1.5B SFT baseline, as expected, but it has
substantial correct CALL behavior and near-perfect original abstention. The stress
slice remains challenging and can reveal protocol/decision improvement.

## DPO screening gate

A future 0.5B DPO candidate must satisfy all of the following on stored internal
evaluations:

- original act accuracy at least 58.33% (no more than five points below baseline);
- original abstention accuracy at least 96.33% (no more than two points below);
- original overall accuracy at least 78.83% (no more than two points below);
- original protocol compliance exactly 100%;
- stress behavior accuracy above 25% and stress protocol compliance at least
  87.5%;
- stress hallucinated-call rate below 50% without eliminating original CALL
  behavior.

These are screening thresholds, not claims that a 0.5B model is production-ready.
No 1.5B preference experiment is authorized unless the complete gate passes.
